# 桌面静态资源

## 用途

图标、品牌资源及打包附属文件。

## 限制

纳入 Git 的应是源资源；安装包放忽略的 release，打包签名密钥放仓库外。

## v0.1 状态

icon.svg 为 SuPilot 图标源，icon.png 与 icon.ico 为对应窗口/Windows 打包资源；不包含签名材料。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../../../AGENTS.md)，目录索引见 [directory-map.md](../../../docs/directory-map.md)。
