# 工作区布局

## 用途

标签页、分屏、面板尺寸、焦点、布局保存和恢复。

## 限制

视图挂载或卸载不能意外启动或销毁 SSH；布局使用稳定会话引用。

## v0.1 状态

为避免重复状态，当前标签/分屏编排集中在 ../app/App.tsx；本目录暂不复制一套布局实现。宽度保存，SSH 会话不跨应用重启恢复。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。
