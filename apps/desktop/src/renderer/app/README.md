# 界面启动与全局设置

## 用途

应用入口、主题挂载、全局设置和界面级状态。

## 限制

Zustand 只保存界面状态；运行中的 SSH 和任务由后台维护。

## v0.1 状态

App.tsx 组织主机/终端/工具/任务/设置入口、固定目标和独立编辑页，state.ts 仅存 UI 设置，demo.ts 是独立内存演示源，style.css 为简化流程样式。Engine 启动时导入用户 `~/.ssh/config` 的 Host 档案，在列表中标记“配置”；它们仍是连接档案，不代表已经启动会话。

简化流程使用石墨灰外壳：顶部稳定导航、主机列表、按需工具、任务摘要和设置覆盖层使用中性层级，蓝色只强调交互、链接和真实输入焦点。QuickOpen.tsx 提供快速打开面板，支持键盘选择与会话复用；主机单击选择不改变当前会话目标。终端由页面外稳定容器承载，隐藏与释放分离；编辑页、设置浮层和任务浮层共用未保存与焦点保护。字号与 ANSI 配色偏好继续独立保存。format.ts 仅格式化显示端点（含 IPv6），不构造执行命令。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

欢迎页通过 snapshotState.ts 区分尚未读到有效快照、请求失败与已读取。订阅的新快照优先于较早的初次请求；读取失败不推断主机数量或 OpenSSH 安装状态，恢复后清除读取错误。错误状态沿用添加档案和演示入口，不增加重试或后台协议。
