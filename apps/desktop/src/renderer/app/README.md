# 界面启动与全局设置

## 用途

应用入口、主题挂载、全局设置和界面级状态。

## 限制

Zustand 只保存界面状态；运行中的 SSH 和任务由后台维护。

## v0.1 状态

App.tsx 组织标签/双窗格/主机/详情/任务，state.ts 仅存 UI 设置，demo.ts 是独立内存演示源，style.css 为工作区样式。

工作区统一采用 VS Code Dark+ 风格：活动栏、远程资源树、打开的会话、平直标签与面板、蓝色状态栏（演示为紫色）。QuickOpen.tsx 提供独立快速打开面板，支持键盘选择与会话复用；左侧筛选独立保留。主机单击选择不改变当前工作标签目标；字号与 ANSI 配色偏好继续独立保存。窄窗口详情通过 Radix 模态侧栏处理焦点与关闭；任务外部导航重置旧筛选，表单关闭及模式切换保护未保存修改。format.ts 仅格式化显示端点（含 IPv6），不构造执行命令。
