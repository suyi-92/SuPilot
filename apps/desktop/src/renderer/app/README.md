# 界面启动与全局设置

## 用途

应用入口、主题挂载、全局设置和界面级状态。

## 限制

Zustand 只保存界面状态；运行中的 SSH 和任务由后台维护。

## v0.1 状态

App.tsx 组织标签/双窗格/主机/详情/任务，state.ts 仅存 UI 设置，demo.ts 是独立内存演示源，style.css 为工作区样式。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../../../../../AGENTS.md)，目录索引见 [directory-map.md](../../../../../docs/directory-map.md)。
