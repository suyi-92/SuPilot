# 界面启动与全局设置

## 用途

应用入口、主题挂载、全局设置和界面级状态。

## 限制

Zustand 只保存界面状态；运行中的 SSH 和任务由后台维护。

## v0.1 状态

App.tsx 组织标签/双窗格/主机/详情/任务，state.ts 仅存 UI 设置，demo.ts 是独立内存演示源，style.css 为工作区样式。Engine 启动时导入用户 `~/.ssh/config` 的 Host 档案，在列表中标记“配置”；它们仍是连接档案，不代表已经启动会话。

工作区统一采用石墨灰外壳：活动栏、远程资源树、打开的会话、平直标签与面板使用中性层级，蓝色只强调交互、链接和真实输入焦点，正式与演示状态栏保持深色并用局部标识表达模式。终端场景的分屏、专注、详情和主机栏操作位于标签条右侧，终端窗格标题持续显示固定目标与端点；名称使用正文级主文字，端点使用次级等宽文字，窄窗保持身份两行和操作同排。主机摘要的“新建”按钮保留完整可访问名称“新建会话”，在窄栏中避免图标与文字裁切。QuickOpen.tsx 提供独立快速打开面板，支持键盘选择与会话复用；左侧筛选独立保留。主机单击选择不改变当前工作标签目标；字号与 ANSI 配色偏好继续独立保存。窄窗口详情通过 Radix 模态侧栏处理焦点与关闭；任务外部导航重置旧筛选，表单关闭及模式切换保护未保存修改。format.ts 仅格式化显示端点（含 IPv6），不构造执行命令。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

欢迎页通过 snapshotState.ts 区分尚未读到有效快照、请求失败与已读取。订阅的新快照优先于较早的初次请求；读取失败不推断主机数量或 OpenSSH 安装状态，恢复后清除读取错误。错误状态沿用添加档案和演示入口，不增加重试或后台协议。
