# 任务界面

## 用途

批量任务列表、单机步骤、结构化结果、只读日志、取消请求与恢复入口。

## 限制

准确呈现等待、失败和结果未知；不能把本地取消请求显示成远端已经取消。

## v0.1 状态

Tasks.tsx 提供任务历史、状态/主机筛选、步骤、只读输出、日志复制与取消请求。列表、当前结果和详情保持同一目标；窄容器使用紧凑任务选择。日志默认保留列对齐，可手动换行；失败步骤优先展示，实时耗时仅用于真实运行任务。仅单机只读任务，无批量调度/恢复向导。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。
