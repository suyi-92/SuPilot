# 任务界面

## 用途

批量任务列表、单机步骤、结构化结果、只读日志、取消请求与恢复入口。

## 限制

准确呈现等待、失败和结果未知；不能把本地取消请求显示成远端已经取消。

## v0.1 状态

Tasks.tsx 提供任务历史、筛选、步骤、只读输出、日志复制与取消请求。仅单机只读任务，无批量调度/恢复向导。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../../../../../../AGENTS.md)，目录索引见 [directory-map.md](../../../../../../docs/directory-map.md)。
