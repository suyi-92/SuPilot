# SuRelay 服务适配插件

## 用途

探测与调用远端 SuRelay，提供统一操作表单、任务和结果。

## 限制

SuRelay 服务端仍独立维护；不复制源码、不硬编码兄弟目录、不假设完整 JSON 接口已存在。

## v0.1 状态

规划中，只有说明和应用展示入口，无探测/安装/配置/卸载。未安装 SuRelay 不影响 v0.1 使用。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../../AGENTS.md)，目录索引见 [directory-map.md](../../docs/directory-map.md)。
