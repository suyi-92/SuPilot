# 内置服务插件

## 用途

由项目维护并随应用发布的 diagnostics、access、surelay 适配。

## 限制

不在加载时自动安装远端服务，不直接读写核心数据库；v0.1 仅注册 Diagnostics。

## v0.1 状态

仅 Diagnostics 注册为可执行内置插件。Access/SuRelay 为规划入口，无安装或远端变更。暂无插件启停设置。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../AGENTS.md)，目录索引见 [directory-map.md](../docs/directory-map.md)。
