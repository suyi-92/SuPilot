# 统一界面组件包

## 用途

基础交互组件、主题、语义状态、表单与步骤展示。

## 限制

不直接请求后台或绑定 SuRelay；业务目标、数据和事件由使用方传入。

## v0.1 状态

src/index.tsx 提供 Radix Dialog/Tooltip、Button、IconButton、Status；theme.css 为应用语义变量，不导出后台代码。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../../AGENTS.md)，目录索引见 [directory-map.md](../../docs/directory-map.md)。
