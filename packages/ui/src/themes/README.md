# 主题与设计变量

## 用途

应用颜色、字体、间距、控件密度和语义状态变量。

## 限制

应用主题与终端 ANSI 配色独立；实际对比度需验证，不散落硬编码主题颜色。

## v0.1 状态

theme.css 已实现石墨深色语义变量和基础控件样式。终端 ANSI 由终端视图独立配置；浅色主题未实现。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。
