# 主题与设计变量

## 用途

应用颜色、字体、间距、控件密度和语义状态变量。

## 限制

应用主题与终端 ANSI 配色独立；实际对比度需验证，不散落硬编码主题颜色。

## v0.1 状态

theme.css 实现 VS Code Dark+ 风格的中性灰语义变量、蓝色强调及紧凑基础控件。侧栏、活动栏、输入框、列表选中和状态都有独立变量。终端 ANSI 由终端视图独立配置；浅色主题未实现。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。

完整规则见 [AGENTS.md](../../../../AGENTS.md)，目录索引见 [directory-map.md](../../../../docs/directory-map.md)。
