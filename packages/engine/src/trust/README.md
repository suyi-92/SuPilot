# 主机身份与信任

## 用途

服务器指纹验证、应用 known_hosts、重装后重新登记和信任记录。

## 限制

不能全局跳过验证、清空系统记录，或将主机密钥与用户登录私钥混为一谈。

## v0.1 状态

首次扫描/指纹确认、一次性五分钟挑战、known_hosts 与变更阻断已实现。不实现重装重置信任，不改系统文件。
