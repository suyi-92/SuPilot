# 交互会话管理

## 用途

PTY 创建、输入输出、尺寸、会话状态、连接退出与资源释放。

## 限制

不与自动化任务共享可输入终端；背压、缓冲上限和断开行为必须明确。

## v0.1 状态

node-pty/ConPTY、认证后随机握手、专用端口、背压、尺寸和释放已实现。会话目标冻结，最多 16 个活跃会话。

正式源码与说明由 SuPilot 独立仓库跟踪；生成产物和本机材料遵守项目忽略规则。
