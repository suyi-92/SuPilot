# 任务调度与访问保护

## 用途

并发、同机资源锁、固定目标、任务状态、取消/恢复和共同访问保护流程。

## 限制

结果未知时不盲目重试；不同进程崩溃或 SSH 断开不能推断远端已经停止。

## v0.1 状态

当前仅单机只读诊断：固定目标、同机互斥、最多四任务、步骤、取消请求与未知状态；没有批量队列或访问变更执行器。
