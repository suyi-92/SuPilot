# 界面约定

本文件是界面实现的起点，目前没有窗口或页面。界面以终端工作区为中心，使用 React 组合统一的桌面交互组件。

## 工作区

| 区域 | 用途 | 行为 |
| --- | --- | --- |
| 左侧主机栏 | 搜索、分组、标签和主机定位 | 可缩放与收起，不默认塞入所有监控指标 |
| 中央工作区 | SSH 标签、分屏、操作表单与任务详情 | 终端占主要空间，复杂操作独立成标签 |
| 右侧详情 | 当前对象摘要、收藏操作、插件入口 | 按需打开，小窗口优先收起 |
| 底部任务区 | 活跃任务、步骤、需要处理的问题 | 平时显示简短状态，需要时展开 |

优先保留 Windows 系统窗口按钮和正常吸附/缩放行为。任何自定义标题栏方案均需验证拖动区域、系统菜单和缩放行为。

## 对象与焦点

- 主机列表单击用于选中，双击用于打开或切换对应连接；用户主动“新建会话”时允许同一主机多个会话。
- 每个终端标签和分屏显示简短主机、用户身份，焦点窗格有明确边界。
- 右侧默认跟随当前工作标签；显式打开某主机详情时也必须显示对应目标。
- 操作表单打开后固定目标；背景导航变化不改变该表单对象，批量操作展示固定目标清单。
- 打开通知、任务进度更新、切换详情不能偷偷抢走终端焦点；模态窗口关闭后恢复合理焦点。
- 复制、粘贴、搜索和应用快捷键必须与 Shell 快捷键协调，不能随意截获 Ctrl+C、Ctrl+D、Ctrl+R 等。

## 视觉与密度

- 深石墨背景、少量冷蓝强调，使用中性色区分层级，避免大量悬浮卡片和装饰效果。
- 起始参考色：应用背景 `#171A20`、终端背景 `#101216`、强调色 `#5B8DEF`；最终在真实界面中验证对比度，不把参考值散写进业务组件。
- UI 使用系统无衬线字体，中文优先清晰；终端使用可配置等宽字体，分别设置字号。
- UI 正文从 14 像素、终端从 14–15 像素开始验证，支持用户调整；不能把所有控件压缩到难以点击或辨认。
- 主题通过语义变量管理，应用主题与终端 ANSI 配色独立；预留浅色和跟随系统。
- 图标统一使用 Lucide，图标按钮有可访问名称、键盘焦点和必要文字提示。

## 操作与插件

- 查询、复制地址和查看日志等常规操作直接执行。
- 访问路径变更、重装登记、卸载等展示目标、修改内容、影响和恢复方法，使用具体动作名称。
- NAT VPS 表单分别写明公网连接端口与服务器监听端口。
- 插件使用统一表单、步骤、结果和错误组件；主机详情只显示少量常用或收藏操作，其他操作可搜索。
- 简单脚本可以成为快捷操作；复杂脚本通过插件提供探测和结构化结果。交互运行与后台任务的入口明确区分。

## 状态与结果

分别表达会话连接、最近检查时间和远端服务状态。尚未探测、信息过期、探测失败、明确不支持与未安装不能混为一谈。

任务连接中断可能导致结果未知，不能直接显示失败或自动重试。状态由文字和图形共同表达，不只靠颜色。

任务日志是只读执行记录，与可输入的终端区分；允许复制、筛选与查看详细日志，但先脱敏并限制输出量。

## 首轮验证场景

1. 十几台主机、两个终端窗格、一个后台任务，同时有长主机名和中文输出。
2. 从指定主机打开 SuRelay 操作页，切换其他终端后仍保持原操作对象。
3. 批量任务同时出现成功、失败、等待输入和结果未知，能准确定位需要处理的主机。
4. Windows 125% / 150% 缩放、小窗口与调整面板宽度；必要时收起辅助面板以保留终端空间。
5. 中文输入法、长文本粘贴、全屏终端程序、键盘导航和连续日志输出。

效果稿和原型中的模拟状态明确标识，不能把可点击原型当作真实 SSH 验证。
