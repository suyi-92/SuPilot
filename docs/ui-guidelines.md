# v0.1 界面约定

当前采用石墨灰外壳与克制蓝色强调：中文、紧凑、终端优先的简化流程，保留 Windows 原生窗口框架。正式外壳不再使用旧的常驻活动栏、主机树、右侧详情或底部任务面板。

| 入口 | 行为 |
| ---- | ---- |
| 主机 | 搜索、分组、标签、OpenSSH 来源、添加/编辑/删除和连接；连接动作复用已有会话。 |
| 终端 | 会话标签、单/双窗格、复制粘贴、关闭和连接主机；页面切换不卸载 TerminalPane。 |
| 工具 | 按需登记真实内置工具；当前接入系统诊断，目标在打开时固定。 |
| 任务 | 顶部摘要浮层与独立结果页共用真实任务数据；完成不跳转、不抢焦点。 |
| 设置 | 覆盖层内分组展示外观、终端、快捷键和关于；保留 `supilot-ui` 偏好。 |

主机编辑是独立页面，只显示表单、返回路径和保存区。设置或任务浮层开启时不销毁草稿；主导航、返回、连接和演示切换离开编辑页前共用未保存保护。

终端资源与页面状态分离。应用始终以稳定 session.id 挂载 TerminalPane；主机、工具、任务和设置只切换可见层，不能发送 `session.close` 或重新 `session.open`。隐藏期间不向零尺寸容器发送 resize，恢复有效尺寸后再 fit；后台输出、认证提示、滚动位置和未发送输入由真实终端保有。

复杂表单位于中央。首次空工作区引导添加主机或演示；加载、OpenSSH 缺失、信任检查、认证失败、中断、Engine 错误有明确反馈。操作页冻结目标，导航不会改动。新建会话与复用会话有不同入口。

## 视觉与键盘

theme.css 统一语义变量：顶部与活动栏 #101216、主内容 #171A20、侧栏 #14171C、抬高表面 #20252D、普通悬停 #272F3A、输入背景 #1B2028。主文字、次文字、辅助文字、边框、选择背景、链接、输入焦点和成功/警告/错误分别建模。标签与树列表平直，输入框和按钮使用小圆角；不使用渐变、大型品牌区或卡片式主机列表。正式和演示状态栏都使用中性深色底，演示通过局部标识和“合成数据”文字表达。

顶部栏约 48px，主内容按 850×600 的最小请求窗口自适应。导航入口使用文字和可访问名称，任务/设置不以高饱和横条常驻。主机行保留完整身份的 title 与可访问名称；终端窗格标题负责目标、端点和连接状态，窄窗仍保持身份与操作可用。快速打开面板支持名称/地址/分组/标签搜索，↑/↓ 选择、Enter 打开或复用会话、Esc 关闭；终端入口显示会话数量。

UI 系统无衬线字体，新配置默认 13px，可设 12–17px；终端 Cascadia Mono / Consolas 等宽，默认 14px，可设 11–22px。正文主要用 rem。ANSI Dark+ / Graphite / Classic 在 Terminal.tsx 独立定义，不改变应用主题；新配置默认 Dark+，已有设置保留。当前只提供深色应用主题，无浅色/跟随系统。

诊断目标、步骤与任务日志采用平直分区，表单使用统一输入框。窄窗格将身份与操作栏排成两行；窗口变窄优先缩减装饰和主机行操作。终端隐藏不卸载会话。任务浮层和设置浮层由 Radix 负责焦点约束、Esc 和外部点击关闭，关闭后回到合理来源而不强制抢终端焦点。

主机表单固定底部保存/取消和连接预览，打开时收起底部任务列表。字段错误同时呈现在字段旁和可聚焦摘要中，摘要链接直达字段。脏表单标签显示圆点，关闭及切换模式前确认丢弃。成功反馈短暂显示，错误保留至手动关闭。

欢迎页按加载、错误、首次使用和已有主机显示当前入口；首次使用优先添加主机，已有主机优先打开快速搜索。设置降为轻量操作，演示模式明确标注合成数据。

首次快照请求失败与已读取的空快照分开表达；没有有效数据时不判断主机数量或 OpenSSH 是否存在。有效订阅快照可以恢复欢迎内容，较早请求的成功或失败不能覆盖新数据。读取失败和 Engine 错误页就近提供添加档案与演示入口，填写不承诺后台保存一定成功。

主机表单先展示名称、地址、实际连接端口、用户名和认证方式，再展示分组、标签、备注；远端 sshd 监听端口位于可折叠的高级记录中，只供记录。校验摘要按字段定位并在高级字段出错时自动展开，固定底部保存区持续可达。

错误说明以 HostInput 的实际结构化 issue 为依据。认证切换保留输入和仍有效的错误；Agent 下如果路径本身违反长度/控制字符约束，仍提供可达的路径修正入口。只检查路径格式，不声称验证文件存在或密钥有效。保存异常使用普通文本，字段错误才提供定位按钮。

诊断页先显示固定目标、四项只读范围和独立 SSH/免交互认证说明，命令与较长执行限制按需展开。任务入口是浮层摘要，完整任务页再显示真实状态、固定目标、结果摘要、步骤和原始日志；cancel-requested、cancelled、interrupted、unknown 与 unavailable 保留各自语义，检查完成不推断服务器健康。

结果摘要的边线与图标遵循摘要 tone。部分项不可用使用 warning，整体状态 badge 仍使用任务的真实 state；不通过改写状态或全局成功色来表达局部限制。

任务列表突出主机、状态和时间；过滤后的当前记录与右侧详情同步，空结果不残留旧详情。从其他入口指定任务时清除旧筛选。失败步骤优先展示；输出默认保留列对齐，可切换自动换行。目标、开始时间、耗时和完成项数集中呈现，模拟运行明确标注。

Lucide 图标、可访问名称、Radix Tooltip/Dialog、统一 Button/IconButton/Status。焦点可见，状态同时有文字与颜色。Ctrl+C / D / R 交给 Shell；Ctrl+Shift+C / V 或工具栏复制粘贴。字号变化同步远端尺寸，标签切换恢复焦点。

## 状态与目标

认证成功必须收到登录后握手；等待、失败、中断分别显示。检查时间和 SSH 状态分开，未探测不显示在线。任务日志为只读记录，取消请求不冒充远端已停止。首次指纹需独立核对；删除主机保留会话/任务快照，关闭活跃终端有确认。
