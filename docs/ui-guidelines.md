# v0.1 界面约定

当前采用石墨灰外壳与克制蓝色强调：中文、紧凑、终端优先的桌面工作区，保留 Windows 原生窗口框架。借鉴工作台布局，但不包含 VS Code 编辑器、扩展宿主或未实现菜单。

| 区域     | 行为                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| 主机栏   | 拖动宽度/收起，名称/地址/标签/分组搜索，分组折叠；单击选中，双击/Enter 打开会话 |
| 中央     | SSH 标签、双窗格左右/上下分屏、主机表单、诊断、任务详情；隐藏标签保持会话       |
| 详情     | 跟随工作标签/焦点窗格的固定目标，窄窗口优先隐藏，可显式打开浮动详情                                 |
| 底部     | 常驻简短任务状态，可展开步骤与结果；复杂详情在中央                              |
| 专注模式 | 收起主机、详情与任务，保留终端和标签                                            |

复杂表单位于中央。首次空工作区引导添加主机或演示；加载、OpenSSH 缺失、信任检查、认证失败、中断、Engine 错误有明确反馈。操作页冻结目标，导航不会改动。新建会话与复用会话有不同入口。

## 视觉与键盘

theme.css 统一语义变量：顶部与活动栏 #101216、主内容 #171A20、侧栏 #14171C、抬高表面 #20252D、普通悬停 #272F3A、输入背景 #1B2028。主文字、次文字、辅助文字、边框、选择背景、链接、输入焦点和成功/警告/错误分别建模。标签与树列表平直，输入框和按钮使用小圆角；不使用渐变、大型品牌区或卡片式主机列表。正式和演示状态栏都使用中性深色底，演示通过局部标识和“合成数据”文字表达。

活动栏宽 48px，顶部栏 36px，标签最小高度 36px，主机行约 30px，底部状态栏 24px。活动项以左侧链接色线标识，活动窗格以轻边界标识；真实终端获得输入焦点时才显示输入焦点边界。终端场景的分屏、专注、详情和主机栏操作位于标签条右侧，窗格标题只负责目标、端点和连接状态。主机地址通过悬停提示及选中详情展示；“打开的会话”切换现有标签，顶部提供独立快速打开面板，支持名称/地址/分组/标签搜索，↑/↓ 选择、Enter 打开或复用会话、Esc 关闭。左侧筛选独立保留；主机列表支持 ↑/↓ 导航，工作标签支持 ←/→/Home/End。

UI 系统无衬线字体，新配置默认 13px，可设 12–17px；终端 Cascadia Mono / Consolas 等宽，默认 14px，可设 11–22px。正文主要用 rem。ANSI Dark+ / Graphite / Classic 在 Terminal.tsx 独立定义，不改变应用主题；新配置默认 Dark+，已有设置保留。当前只提供深色应用主题，无浅色/跟随系统。

诊断目标、步骤与任务日志采用平直分区，表单使用与工作台一致的输入框。窄窗格将身份与操作栏排成两行；窗口变窄优先收起详情；专注模式同时收起活动栏、主机栏、详情和任务面板。终端隐藏不卸载会话。窄窗口显式打开详情后，Radix 负责焦点约束、Esc 和外部点击关闭；任务区按实际容器宽度切换历史列表和紧凑选择器。

主机表单固定底部保存/取消和连接预览，打开时收起底部任务列表。字段错误同时呈现在字段旁和可聚焦摘要中，摘要链接直达字段。脏表单标签显示圆点，关闭及切换模式前确认丢弃。成功反馈短暂显示，错误保留至手动关闭。

任务列表突出主机、状态和时间；过滤后的当前记录与右侧详情同步，空结果不残留旧详情。从其他入口指定任务时清除旧筛选。失败步骤优先展示；输出默认保留列对齐，可切换自动换行。目标、开始时间、耗时和完成项数集中呈现，模拟运行明确标注。

Lucide 图标、可访问名称、Radix Tooltip/Dialog、统一 Button/IconButton/Status。焦点可见，状态同时有文字与颜色。Ctrl+C / D / R 交给 Shell；Ctrl+Shift+C / V 或工具栏复制粘贴。字号变化同步远端尺寸，标签切换恢复焦点。

## 状态与目标

认证成功必须收到登录后握手；等待、失败、中断分别显示。检查时间和 SSH 状态分开，未探测不显示在线。任务日志为只读记录，取消请求不冒充远端已停止。首次指纹需独立核对；删除主机保留会话/任务快照，关闭活跃终端有确认。
